# Ideas

Things to build later, grouped by the screen they belong to.

## Settings

### Audio format

A **Format** section so recordings can be saved in different audio formats
(e.g. the browser's native WebM, MP3, WAV, M4A) rather than only the format
the recorder produced.

- Pick the default saved format for new recordings.
- The format also becomes an explicit choice next to the **Share** button in
  view mode: a small dropdown that selects which format the share/download
  action produces, so a single recording can be handed out in different
  formats without changing the saved original.
